BookSaaS — это готовое SaaS-решение для мастеров сферы услуг (барберы, маникюр, массаж, косметология и другие). Платформа предоставляет личную страницу записи для клиентов, умный календарь, CRM с историей визитов, финансовую аналитику и инструменты для удержания клиентов.

🚀 Регистрация за 2 минуты, пробный период 14 дней, затем ₽990/месяц.

🚀 Быстрый старт

1️⃣ Клонирование репозитория

bash
git clone https://github.com/yourusername/booksaas.git
cd booksaas
2️⃣ Установка зависимостей

bash
pip install -r requirements.txt
3️⃣ Настройка переменных окружения

Создайте файл .env в корне проекта:

env
MAIL_USERNAME=your_email@gmail.com
MAIL_PASSWORD=your_app_password
MAIL_SERVER=smtp.gmail.com
MAIL_PORT=465
MAIL_USE_TLS=False
MAIL_USE_SSL=True
APP_URL=http://localhost:5000
TRIAL_DAYS=14
MONTHLY_PRICE=990
4️⃣ Запуск приложения

bash
python app.py
Приложение будет доступно по адресу: http://localhost:5000

5️⃣ Первая регистрация

Откройте /register
Создайте аккаунт мастера
Настройте услуги и расписание в личном кабинете
Поделитесь ссылкой на свою страницу записи с клиентами
